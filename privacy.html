Privacy Policy — rclone Backup

Last updated: November 14, 2026

rclone Backup is a personal tool operated by John Signorino. It is used by its owner only, to copy his own Google Drive files to his own home storage as a backup.

What the tool accesses

With the owner’s authorization, the tool reads and downloads the owner’s own Google Drive files and folders, using the Google Drive API through the open-source program rclone.

What the tool stores

Copies of the owner’s files are stored only on the owner’s own hardware in his home. The sign-in token rclone needs is stored only on the owner’s own computer. Nothing is uploaded to any third-party service.

What the tool does not do

  • It does not access anyone else’s files or account.
  • It does not share, sell, or disclose the owner’s data to any third party.
  • It does not use the data for advertising, analytics, or profiling.
  • It does not modify or delete files in Google Drive; it only reads and copies them.

Revoking access

The owner can revoke the tool’s access at any time from the Google Account permissions page (myaccount.google.com, under Security and third-party access), which immediately prevents any further access.
