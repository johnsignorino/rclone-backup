rclone Backup

rclone Backup is a personal backup tool operated by John Signorino for his own private use.

The tool uses the open-source program rclone together with the Google Drive API to make a monthly copy of the owner’s own Google Drive files onto the owner’s own home storage, so that a copy of his files exists outside Google in case of accidental deletion, corruption, or loss of account access.

The tool has exactly one user: its owner. It is not offered to the public, it has no sign-up, and no one else’s files are ever accessed.
